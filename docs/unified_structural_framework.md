# Structural Invariance Across Modalities: Unified Framework

**Core Hypothesis**:

```
observable signal ≠ underlying structured object
```

Speech, text, signing, gesture, and music are different **projections** through different physical channels of the same fundamental phenomenon: structured semantic/intentional states under continuous transformation.

## The Unified Pipeline

```
S → C → B_t → O_t → Ŝ
```

Where:
- **S**: Latent semantic/intentional structure
- **C**: Hierarchy of controlled perceptions (PCT)
- **B_t**: Historically contingent behavior (linguistic/gestural/musical)
- **O_t**: Observable projection (what survives)
- **Ŝ**: Reconstructed structure (inverse problem)

## Central Research Question

**Which structures remain invariant enough to be reconstructed when their physical realizations continuously change?**

This unifies:
- Historical linguistics (language change over time)
- Gesture recognition (embodied semantic reconstruction)
- Music cognition (structural relationships across performances)
- Audio semantics (prosody/affect from waveforms)
- Sign language (distributed meaning across articulators)

## Three Major Theoretical Families

### 1. Linguistic Theories

#### Structural Semantics

Extends structuralist linguistics from relations among signs to relations among **admissible transformations**.

**Key Concepts**:
- Scope Calculus
- Scope Geometry
- Bounded contexts
- Boundary constraints
- Structural-semantic preservation
- Representation Invariance Theorem

**Intellectual Lineage**:
Saussure → Hjelmslev → Lyons → Frege → Peirce → Greimas → Coseriu → Chomsky → Cognitive Semantics

**Core Insight**: Meaning resides not in individual signs but in the **transformations they admit**.

#### Semantic Relaxation Networks (SRN)

*Language Generation as Constraint Stabilization in Admissibility Space*

**Core Idea**: Language is the observable residue of a constraint-resolution process, not fundamentally a sequence of predicted tokens.

**Mechanism**:
```
Semantic structures → Constraint relaxation → Admissible configurations
                                                    ↓
                                    Grammar + Prosody (pressure fields)
                                                    ↓
                                    Linearization (observable sequence)
```

**Implication**: Syntax is a **projection** of stabilized meaning, not its primary generator.

#### Analogy as Reduction

Analogy isn't similarity detection—it's **constrained reduction/collapse** that transports structure while narrowing admissible transformations.

**Connections**:
- Morphological regularization
- Johansson's *Construction as Reduction*
- Hofstadterian analogy bundles
- Spherepop membranes
- β-reduction

**Key Insight**: Analogical reasoning preserves structural relationships while reducing dimensionality.

#### Negation Before Logic

*Inferential Fields, Orientation Reversal, and the Geometry of Admissible Inference*

**Model**: Inferential field F = (X, R, ω, A)
- X: domain
- R: relations
- ω: orientation
- A: admissibility

**Core Operation**: Negation as orientation reversal:
```
N(ω) = -ω
```

Not merely Boolean insertion—**geometric transformation** in inferential space.

### 3. Music, Audio, and Prosody

#### Audio as Prosodic Text

*Audio Semantic Encoding*

**Decomposition**:
```
W → (T, P, V, E)
```

Where:
- **T**: Linguistic/textual structure
- **P**: Prosodic information (pitch, timing, rhythm)
- **V**: Vocal identity
- **E**: Affective structure

**Insight**: Waveform is an unnecessarily **entangled representation** of more structured generative object.

#### Music Structure

Analogous decomposition for music:
```
Waveform → (Score-like relations, Tempo, Dynamics, Articulation, 
            Instrumental identity, Mixing)
```

**Connections**:
- Phoenix Protocol (audio restoration)
- Structural invariance of emotion
- Affect survives representation changes

**Why?**: Relationships involving peak timing, force, rhythm, jitter carry invariant structure beyond particular signal substrate.

#### Musical Gesture Cognition

**Core Idea**: Musical gesture cognition is an **inverse reconstruction problem**.

Bodily motion, posture, temporal trajectories → Rhythm, pitch, harmony

**Key Insight**: Semantic object isn't adequately represented by:
- Any one frozen pose
- Any one musical note
- Any one waveform sample

Meaning is **distributed across temporal structure**.

## The Common Theory

Looking across all domains:

### Observable ≠ Structure

| Modality | Latent Structure | Observable Projection |
|----------|------------------|----------------------|
| Language | Semantic constraints | Linear sequence |
| Gesture | Embodied intention | Motor trajectory |
| ASL | Distributed meaning | Handshape + movement + location |
| Audio | Semantic + prosodic + affect | Waveform |
| Music | Temporal relationships | Performance |

### Projection and Inverse

**Forward**: Structure → Projection → Observable
```
SRN: Semantic constraint → Linearization → Utterance
Gesture: Intention → Motor trajectory → Configuration
ASL: Sign meaning → Articulation → Observable handshape
Audio: Structure → Encoding → Waveform
Music: Score + interpretation → Performance → Sound
```

**Inverse**: Observable → Reconstruction → Structure
```
Text as Substrate: Projection → Inverse reconstruction → Latent structure
```

### Why Projections Change: Perceptual Control Theory

**Key Insight**: An organism needn't preserve a particular output form if what it's actually controlling is a **higher-level perception**.

**Equivalence Classes**:
Different gestures, pronunciations, prosodic contours, or musical actions can be **equivalent** insofar as they maintain the relevant controlled variable.

**Example**:
- Control goal: "Be understood"
- Multiple linguistic forms achieve this
- Forms can change while perception remains controlled
- Observable: Different words over time
- Invariant: Comprehension

## Structural Invariance Principles

### 1. Projection Loses Information

**Always**: O_t contains less information than S

**Different modalities lose different information**:
- Language: Loses semantic alternatives, temporal ordering of constraints
- Gesture: Loses internal state, intention alternatives
- Music: Loses score structure, interpretive choices
- Audio: Loses separation of channels (text, prosody, affect, identity)

### 2. Multiple S → Same O_t

**Indistinguishability**:
```
S₁ ≠ S₂  but  O_t(S₁) ≈ O_t(S₂)
```

**Examples**:
- Different semantic structures → same utterance
- Different intentions → same gesture
- Different affects → same prosody
- Different scores → same performance

**Implication**: Reconstruction Ŝ may be **fundamentally ambiguous**.

### 3. Control Processes are Hidden

**PCT Contribution**: 
- C (controlled perceptions) are **not observable** in O_t
- Only B_t (behavioral output) is observable
- Reference signals, error histories are hidden

**Implication**: Can reconstruct **patterns** but not **processes**.

### 4. Structural Relationships Survive Better Than Tokens

**Invariants**:
- Relational structure
- Transformational constraints
- Admissibility boundaries
- Geometric properties

**Non-Invariants**:
- Specific lexical items
- Exact gesture configurations
- Precise waveform values
- Individual performance choices
